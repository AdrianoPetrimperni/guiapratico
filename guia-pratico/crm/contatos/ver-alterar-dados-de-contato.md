# Ver / Alterar dados de contato

Manter os **dados de contato** atualizados e acessíveis é crucial para uma gestão eficiente de relacionamentos na plataforma **Táime Pro**. Este guia fornecerá instruções detalhadas sobre como **visualizar** e **alterar** as informações dos contatos, assegurando que todos os dados relevantes estejam sempre corretos e atualizados.

{% hint style="success" %}
**Pré-requisitos**:

* **Acesso à conta** na plataforma  **Táime Pro**..
{% endhint %}

**Passo 1**: Na tela inicial, acesse o menu **"Atendimentos"**. Selecione o contato que deseja **visualizar** ou **alterar** os dados e clique sobre ele para que a janela de conversa seja aberta. Em seguida, clique no ícone, ![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FpWUSRo7FcdG7GmTdYDRs%2Fimage.png?alt=media\&token=10468960-8577-4b7c-9772-896a856bbed5), e uma aba com os **dados** do contato será exibida na lateral direita da tela

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FZZ35gsiX1SDKgWr7pRk1%2F10.png?alt=media\&token=d1689230-515a-47ab-b405-74addb4a78db)

**Passo 2:** No canto superior direito da tela de dados do contato, **clique** no **ícone**![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2F1dMYbEpXpq0n7z8XwdzT%2Fimage.png?alt=media\&token=47bad4f1-eee1-4a32-b6d0-a39d0dc3cfb3)para editar os **dados do contato**.

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FRrCgtnjABrQNMvkSiO5Y%2F11.png?alt=media\&token=5a3ad614-47eb-47fc-a9c7-44e5bec93450)

**Passo 3:** Após **clicar** no **ícone de edição**, os campos do contato serão habilitados para **edição**. Realize as alterações desejadas e, ao finalizar, **clique** em **"Salvar"** para confirmar as mudanças.

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FugwzjAn3IhaNnc9pHWnm%2F4.png?alt=media)
