# Tempo de segurança

O tempo de segurança na Táime Pro é uma funcionalidade que permite inserir um tempo de segurança de alguns segundos antes de enviar as mensagens aos contatos. Esse intervalo de tempo permite que você revise a mensagem e, se necessário, cancele o envio antes que ela seja enviada definitivamente.

{% hint style="success" %}
**Pré-requisitos:**

* Ter acesso a plataforma Táime Pro com perfil de administrador.
* Habilitar a funcionalidade na plataforma
{% endhint %}

**Para habilitar a funcionalidade**

**Passo 1:** Na tela inicial, clique no menu **“Apps”** em seguida clique na opção **“Mais apps”.**

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2F7i6ThkQhevkXjUwROqqW%2Fprint.png?alt=media\&token=c52ae1a4-0332-4ab4-a4fd-fa48575550ce)

**Passo 2:** Localize o aplicativo "Tempo de Segurança" e clique em habilitar.

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FLQWdGdamVRp7iiLGY4Tx%2F1.png?alt=media)

**Passo 3:** Uma tela de configuração será aberta. Ative a chave para habilitar o aplicativo e defina o tempo de segurança, que pode ser de até 15 segundos. Finalmente, clique em "Salvar" para aplicar as configurações.

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FEUcHPHdrAcdaN2yYxiof%2F2.png?alt=media)

#### **Veja em funcionamento** <a href="#id-6veiebr6bpl6" id="id-6veiebr6bpl6"></a>

Se você enviou uma mensagem com um erro de digitação ou qualquer outro problema, pode cancelar o envio clicando em "Cancelar".

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2F8cutdSxj24MHbYBbwFBl%2FScreenshot.png?alt=media\&token=1caf21f7-1d5a-4d29-9366-401202a71457)

A mensagem será então marcada como "Mensagem apagada".

E o texto volta para a barra de digitação para ser editado ou apagado.

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2F0RqUDLsdVp0pHej5vhU4%2FScreenshot%20\(1\).png?alt=media\&token=3ad131bd-4417-42ae-921a-09bed5c890ec)

**Considerações finais:**

* A mensagem marcada como "Mensagem apagada" não é mostrada para o contato, ficará visível apenas para o usuário da plataforma.
* Após uma mensagem ser enviada não é possível apagá-la, isso é uma limitação da API Oficial da Meta.
