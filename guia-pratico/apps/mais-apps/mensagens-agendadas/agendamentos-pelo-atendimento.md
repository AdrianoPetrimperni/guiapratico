# Agendamentos pelo Atendimento

**Como Agendar uma Mensagem Diretamento pelo Atendimento**

Você pode programar o envio de uma mensagem para o futuro sem sair da tela de conversa do cliente.

Siga os passos abaixo:

**Passo 1:** Acesse a Funcionalidade

* No rodapé da conversa, clique no ícone de anexo (📎) e, em seguida, na opção “Mensagens Agendadas”.

**Passo 2:** Defina a Data e o Conteúdo

* Na janela "Novo agendamento" que será aberta, preencha os seguintes campos:
  * **Data e Horário:** Defina quando a mensagem deverá ser enviada.
  * **Conteúdo:** Escolha se deseja enviar um Modelo de mensagem ou iniciar um Chatbot.

**Passo 3:** Salve o Agendamento

* Após preencher as informações, clique em "Salvar".

{% hint style="success" %}
**Praticidade**

Ao agendar a partir de um atendimento, o sistema preenche automaticamente o Canal e a Equipe com os dados da conversa atual, tornando o processo mais rápido e prático.
{% endhint %}

**Como Visualizar os Agendamentos de um Contato**

Para ver um histórico de todas as mensagens que foram ou estão agendadas para um contato específico diretamente pela tela de atendimento, siga os passos abaixo:

**Passo 1:** Abra os Dados do Contato

* Com o atendimento do contato selecionado, clique no ícone de "Detalhes" no cabeçalho da conversa para abrir o painel lateral de informações.

**Passo 2:** Acesse a Aba de Agendamentos

* No painel lateral, clique no ícone da aba "Mensagens agendadas" (representado por um relógio 🕙) para visualizar a lista.

**Passo 3:** Consulte o Histórico

* A lista exibirá todos os agendamentos para aquele contato, incluindo o status de cada um (enviado, cancelado, falha, etc.).

**Passo 4:** Detalhe e Reagende (Opcional)

* Ao clicar sobre um agendamento na lista, uma nova janela com todos os detalhes daquela mensagem será exibida.
* Nesta tela de detalhes, se o agendamento tiver um status que permite a edição ("Falha" ou "Cancelado"), o botão "Reagendar" estará disponível para você.
