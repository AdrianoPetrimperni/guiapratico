# Arquivar campanha

**Arquivar campanhas na plataforma Táime Pro** é um processo simples e importante para manter a organização e o histórico das atividades de marketing. O arquivamento permite que as campanhas concluídas ou não ativas sejam armazenadas de forma segura, facilitando o acesso futuro para análise e referência. Este guia irá ajudá-lo a entender como **arquivar suas campanhas** de forma eficaz e organizada.

{% hint style="success" %}
**Pré-requisitos**:

* **Acesso à plataforma Táime Pro**&#x20;
* Somente os usuários com **perfil de Administrador** podem **arquivar campanhas**.
{% endhint %}

**Passo 1:** Na tela inicial da plataforma, clique em **"Apps"**. O menu de opções será aberto; em seguida, clique em **"Campanhas"**.

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FfyPnMemk9ijiVVfBLYuB%2F12.png?alt=media\&token=81944353-8f42-4407-b059-b4fd1c44460b)

**Passo 2:** Uma tela com todas as campanhas realizadas será aberta. **Selecione a campanha** que deseja arquivar e clique sobre ela.

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FeNThmM53Kypk7Bnizqt8%2F24.png?alt=media\&token=f0631dcf-d069-4f3f-80db-1bb3650e1504)

**Passo 3:** A tela com os dados da campanha selecionada será aberta. Para **arquivar**, basta clicar no **ícone de arquivo**, ![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FHxmuwpMEPbzjd6Mm0BjZ%2F2.png?alt=media), localizado no canto superior direito. Uma mensagem de confirmação aparecerá no rodapé, informando que a campanha foi **arquivada com sucesso**.

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FYbJy5TIDlwjwmPJ4xviU%2F25.png?alt=media\&token=5767bb1e-53c0-4cf1-a4b6-72d0c00437fb)

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FZGVcCq0WZJTr4QC4tGwJ%2F4.jpeg?alt=media)

**Passo 4:** Para visualizar as campanhas **arquivadas** ou, se desejar, desarquivar alguma, basta clicar na opção **"Arquivadas"**. Uma nova janela contendo **somente** as campanhas arquivadas será aberta.

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FhTHJjXbckFCxKPF6NYlN%2F26.png?alt=media\&token=6e3c8bfb-dcad-40a3-827c-c7aa2bfa3fb5)

**Passo 5:** Para visualizar ou desarquivar uma campanha, basta clicar sobre ela para abrir seus detalhes. Se você clicar no ícone de **arquivo**, a campanha será desarquivada e uma mensagem de **"Campanha desarquivada com sucesso"** aparecerá. A campanha, então, voltará para a tela inicial de **Campanhas**.

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FOsf9FO1gGTteYkA4uzEF%2F27.png?alt=media\&token=44c10c5a-23c3-4a26-a8de-e59dd05168fc)

**Considerações Adicionais:**

* É possível **arquivar** e **desarquivar** qualquer campanha, independentemente de seu **status**.
