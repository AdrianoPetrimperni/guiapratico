# Finalizar sequência

Finalizar uma sequência na Táime Pro é uma ação importante para encerrar campanhas de automação ou séries de mensagens que não são mais necessárias. Este guia fornecerá instruções detalhadas sobre como finalizar uma sequência, garantindo que as comunicações automáticas sejam adequadamente encerradas.

**Pré-requisitos:**

{% hint style="success" %}
**Pré-requisitos:**

* Ter acesso a plataforma Táime Pro com perfil de administrador.
* Ter uma sequência de mensagens ou chatbots já criada na plataforma.
* Ter mensagens do tipo sequência aprovadas na plataforma.
* Ter um bot de automação já definido na plataformama
{% endhint %}

**Passo 1:** Na aba de Apps, selecione a opção **"Sequências".**

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FOQzXseGTOx0UUP7YHcCH%2F0.png?alt=media)

**Passo 2:** No momento em que você insere uma nova etapa, a plataforma automaticamente adiciona a etapa de finalizar a sequência.

Veja na imagem abaixo

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FaYlSGBQpfoHgjk5mfRbl%2F1.png?alt=media)

**Considerações finais:**

* Incluir e excluir contatos nas sequências é feito de forma manual.
* Como se trata de uma mensagem ativa enviada para um ou mais contatos ela será cobrada pela META.
