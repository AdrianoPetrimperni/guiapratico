# Cadastrar modelos de mensagem

Modelos de mensagem são textos padronizados criados para facilitar o início de conversas em diversos contextos, como atendimento ao cliente, vendas e retomada de conversas. Eles garantem uma comunicação eficiente, consistente e profissional.

{% hint style="success" %}
**Pré-requisitos:**

* Acesso à conta na plataforma Táime Pro.
* Somente os usuários com perfil de Administrador podem cadastrar modelos de mensagens do tipo Atendimento, Campanha e Sequência.
{% endhint %}

**Passo 1:** Na tela inicial da plataforma, clique na opção “Ajustes”, o menu de opções se abrirá, clique em Modelos de Mensagens.

<figure><img src="../../.gitbook/assets/image (19).png" alt=""><figcaption></figcaption></figure>

**Passo 2:** Selecione o modelo que deseja cadastrar.

Tipos de modelos de mensagens

**Atendimento:** Mensagens transacionais usadas para iniciar uma conversa com o cliente.

**Campanha:** Mensagens de marketing usadas para divulgar produtos ou serviços.

**Sequência:** Essa funcionalidade permite configurar sequências de mensagens ou chatbots para contatos específicos, definindo intervalos programados e horários permitidos, além de gerenciar contatos nas sequências via ações no chatbot.

<figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure>

**Passo 3:** Preencha os campos necessários do modelo de mensagem.

**Nome do Modelo:**

* **Descrição:** Nome único que identifica o modelo de mensagem.
* **Exemplo:** "Boas-vindas Cliente Novo"

**Canal:**

* **Descrição:** Este campo especifica o meio pelo qual a mensagem será enviada. Pode conter um ou mais número(s) de Whatsapp conectado(s) na API Oficial.

**Categoria:**

* **Descrição:** Categoria que define o tipo de mensagem,

**Utilidade:** Deve ser utilizada para envio de informações solicitadas pelo cliente, como a situação de um pedido, acompanhamento de entrega, envio de faturas, entre outros.

**Marketing:** Utilize para iniciar ou reativar uma conversa, enviar campanhas ou para outras demandas que não se encaixem nos requisitos da categoria Serviço.

**Dispoível para:**

* **Descrição:** É possivel definir para quais equipes este modelo de mensagem ficara disponível.

**Adicione o texto da mensagem.** É possível utilizar parâmetros no texto para automatizar a personalização da mensagem. Para definir um campo personalizado, basta adicionar o nome do campo entre colchetes \[ ]. Por exemplo: \[NOME].

<figure><img src="../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure>

Alem do texto é possível adicionar foto, video, anexar arquivo e adicionar botões\
\
![](<../../.gitbook/assets/image (25).png>)![](<../../.gitbook/assets/image (26).png>)

São dois tipos de botões, **Resposta rápida** e **Abrir página**. O botão de resposta rápida é utilizado para dar sequência na conversa, facilitando o fluxo da conversa com o atendente. O botão **Abrir página** permite adicionar um link para direcionar o contato para uma nova pagina.

<figure><img src="../../.gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure>

**Passo 4:** Clique em salvar e o modelo de mensagem e ele será enviado automaticamente para aprovação. A Meta analisará e aprovará ou rejeitará o modelo.

**Passo 5:** Monitorar o Status do Modelo

* Após enviar o modelo, você poderá monitorar seu status (Ativo, Em Análise, Reprovado) diretamente na plataforma Táime Pro CRM.
* Caso o modelo seja reprovado, revise e faça as alterações necessárias antes de enviar novamente.

**Considerações Adicionais:**

* O tempo de aprovação do modelo de mensagem é definido pela META. Contas mais novas e com menor taxa de feedback tendem a demorar mais para ter seus modelos aprovados, enquanto contas mais antigas com maior taxa de feedback geralmente têm um processo de aprovação mais rápido. Existem muitas outras variáveis que também influenciam esse resultado.
