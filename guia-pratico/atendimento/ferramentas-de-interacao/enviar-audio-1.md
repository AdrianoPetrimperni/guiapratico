# Enviar Áudio

O envio de mensagens de áudio no **Táime Pro** é uma funcionalidade que permite uma comunicação mais direta e personalizada com seus contatos. Seja para enviar informações detalhadas, feedback ou mensagens rápidas, os áudios são uma maneira eficaz de se comunicar. Este guia explicará como enviar áudios dentro da plataforma **Táime Pro**.

{% hint style="success" %}
**Pré-requisitos**:

* Acesso à conta na plataforma **Táime Pro**.
{% endhint %}

**Passo 1**: Na tela inicial, acesse o menu 'Atendimentos'. Selecione o contato para o qual deseja enviar o arquivo de áudio, para que a janela de conversa seja aberta. Em seguida, clique no ícone ![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FcstBUSoYDycREWqU65IW%2F0.png?alt=media) e um menu de opções será exibido. Escolha a opção ‘Áudio' para continuar.

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2F6AB7nyq33QzyiEmSTMbq%2F1.png?alt=media)

**Passo 2**: Após clicar na opção 'Áudio', a pasta do seu computador será aberta para que você possa escolher o arquivo que deseja enviar. Selecione o arquivo e clique em 'Enviar’.

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FCVUj6k1de42z49yd29uS%2F2.png?alt=media)

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FhFTbstgyEJiT684yzlMf%2F3.png?alt=media)

**Passo 3**: Após o áudio ser enviado, ela estará disponível para que o contato ouça ou faça download.

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FKIEhah5y0pgmrJKDuJMf%2F4.png?alt=media)

**Considerações Adicionais**:

* A plataforma segue as regras do Whatsapp para tamanho de envio de arquivos, no caso de áudios o tamanho depende do tipo de canal, sendo para **Instagram e Messenger = 25MB e API oficial = 16 MB.** Caso o arquivo ultrapasse a regra do Whatsapp a plataforma envia o link para que o contato faça o download.
