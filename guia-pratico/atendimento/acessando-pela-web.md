# Acessando pela Web

Sempre que você acessar sua conta, um **código de validação** será enviado para garantir a **segurança do seu login**. Vale lembrar que, se você não realizar o processo de logout clicando em **"Sair",** sua sessão permanecerá ativa na plataforma.

Pré-requisitos

{% hint style="success" %}
**Pré-requisitos**\
\
Disponível para todos os usuário cadastrados na plataforma, com um número que tenha whatsapp e/ou e-mail.

Cadastre os domínios @taime.pro na whitelist de seu servidor de email para que não tenha problema para receber nosso código por email.

Sempre acessar usando como navegador Google Chrome.
{% endhint %}

Passo 1: Acesse o site [https://taime.pro](https://app.taime.pro/) Preencha a informação de acesso, pode ser o telefone ou e-mail utilizado no cadastro do usuário. Você receberá um código de 6 dígitos no canal de comunicação escolhido e clique no botão entrar.

Considerações Adicionais

Caso seja seu primeiro acesso, após executar os passos acima será necessário aceitar os [Termos de Uso e Privacidade.](https://app.taime.pro/terms) Basta clicar na caixa de seleção e, em seguida, clicar em concordo.

<figure><img src="../../.gitbook/assets/image (13).png" alt=""><figcaption></figcaption></figure>

Você receberá um novo código de 6 dígitos para o mesmo canal de comunicação que utilizou para fazer o login. Insira o código e clique em continuar.
