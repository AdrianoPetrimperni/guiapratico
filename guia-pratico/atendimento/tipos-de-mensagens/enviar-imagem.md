# Enviar imagem

Enviar **imagens** na plataforma é uma funcionalidade simples, mas extremamente útil para enriquecer os dados do seu contato e tornar a comunicação mais **visual**. Este artigo guiará você pelos **passos detalhados** para enviar imagens na plataforma.

{% hint style="success" %}
**Pré-requisitos**:

* Acesso à conta na plataforma **Táime Pro.**
{% endhint %}

**Passo 1**: Na tela inicial, acesse o menu **"Atendimentos"**. Selecione o contato para o qual deseja enviar a imagem, para abrir a janela de conversa. Em seguida, clique no ícone ![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FvicReblcSN7rU9RRGnPp%2Fimage.png?alt=media\&token=d2d61542-a61d-434d-8f0e-54d43f8f8dc4)e um menu de opções será exibido. Escolha a opção **"Imagem"** para continuar.

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FhYp1rwf00qp6WjHDPZcW%2F42.png?alt=media\&token=348a8f54-13af-4a9c-afda-29a2315c2a12)

**Passo 2**: Após clicar na opção **"Imagem"**, a pasta do seu computador será aberta para que você possa escolher o arquivo que deseja enviar. Selecione a(s) **imagem(s)** e clique em **"Enviar"**. Após a **imagem** ser enviada, ela estará disponível para **visualização** ou **download** pelo contato.

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2F3ZRfs5oIkjLOKET1MrOV%2F43.png?alt=media\&token=4ef2404b-4b2d-41f7-b04f-a37754a9896d)

**Considerações Adicionais**:

* A plataforma segue as regras do **WhatsApp** para o **tamanho de envio de arquivos**. No caso de **imagens**, o **tamanho máximo** é de **5 MB**.
* Caso o arquivo ultrapasse esse limite, a plataforma enviará um **link** para que o contato possa fazer o **download**.
