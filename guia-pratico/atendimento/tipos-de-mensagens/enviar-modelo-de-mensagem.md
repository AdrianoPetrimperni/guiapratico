# Enviar Modelo de Mensagem

Enviar **modelos de mensagem** no **Táime Pro** é uma prática essencial para iniciar ou reiniciar uma conversa com um contato. Este artigo guiará você pelos **pré-requisitos** necessários e pelos **passos detalhados** para enviar modelos de mensagem na plataforma.

{% hint style="success" %}
**Pré-requisitos**:

* Acesso à conta na plataforma **Táime Pro**.
* Ter **modelo de mensagem do tipo Atendimento** cadastrado e ativo.
{% endhint %}

**Passo 1**: Na tela inicial, acesse o menu **"Atendimentos"**. Selecione o contato para o qual deseja enviar um modelo de mensagem, para abrir a janela de conversa. Em seguida, clique no ícone ![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FSKHlpA5rJJ1VDNm66eCx%2Fimage.png?alt=media\&token=1313a813-56b6-4217-ba8c-84fd03b51f0d) e um menu de opções será exibido. Escolha a opção **"Modelo de Mensagem"** para continuar.

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FHrj3mzOi6Q5FE0Qhtf4y%2F33.png?alt=media\&token=8d88459e-8ef8-43e6-b700-b32e01258c34)

**Passo 2**: Após clicar na opção **"Modelo de Mensagem"**, será aberto um menu com os **modelos de mensagens disponíveis**. Selecione o modelo desejado e clique em **"Continuar"**.

<figure><img src="../../../.gitbook/assets/image (37).png" alt=""><figcaption></figcaption></figure>

**Passo 3**: Após selecionar o modelo desejado, preencha os **parâmetros da mensagem** (se for o caso). Em seguida, clique em **"Enviar Mensagem"**.

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FgnnoCr2BAXvQZ3SaXP34%2F3.png?alt=media)

**Passo 4:** Após enviar o modelo de mensagem, ele será exibido na **janela de conversa**.

![](https://3176979156-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F3HTAyLM7hzj1t6Nt4ii2%2Fuploads%2FNIKZAJaPPNsJdkr2n0gF%2F35.png?alt=media\&token=d50b3998-8a71-4d3d-922b-0c5a3df2cd14)

**Considerações Adicionais**:

* Se o modelo de mensagem for utilizado para **iniciar** ou **reiniciar** uma conversa com o contato, a janela de conversa só será reaberta quando o contato interagir de alguma forma. Isso inclui o envio de uma **mensagem de texto**, **emoji**, **vídeo** ou **arquivo**.
* Se o contato demorar para interagir ou não responder, é possível **enviar um novo modelo de mensagem** para tentar engajar o contato e reabrir a janela de conversa. Pode-se enviar o **mesmo modelo de mensagem** utilizado inicialmente ou qualquer outro modelo, desde que seja do **mesmo tipo** do primeiro (marketing ou utilidade).
